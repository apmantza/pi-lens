### Highlights

- **Breaking for MCP clients:** `pilens_module_report`, `pilens_read_symbol` and `pilens_read_enclosing` now refuse a call that passes only `file`; pass `path` instead. These tools, and `pilens_effective_config`, now advertise `path` as their only file argument.
- **Linters hang and fail less noisily:** a linter that times out is skipped for the rest of the session instead of costing a timeout on every edit, and a project `.venv` or `node_modules/.bin` linter is picked up once pi trusts the project.
- **Scanner failures stop reading as clean:** a gitleaks or trivy report that is not empty but cannot be parsed, or a jscpd run that never started, now records a failed scan rather than "nothing found"; an empty report still reads as an empty run.
- **False-positive marks stick:** a dismissed cascade error stops coming back, and a mark copied from a truncated cascade line now hides that error.
- **ast-grep 0.51.1+ compatibility:** the bundled rule set loads again on newer ast-grep, which refused the old top-level rule keys.
