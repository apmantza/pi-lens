### Highlights

- **Hotfix for 4.4.11's "invalid request" errors:** with pi-lens 4.4.11 loaded, some providers rejected every turn. Examples are opencode-go beam-free ("Invalid request") and Amazon Bedrock's Anthropic models ("For 'array' type, property 'maxItems' is not supported"). The five tools whose schemas they rejected no longer ask for strict mode, and the three that still do use only keywords strict mode accepts (no `maxItems`, numeric or length bounds), so these providers work again. (#5471, #5480)
- **Language server diagnostics for sibling projects:** an edit to a project outside the session folder now gets language server diagnostics, and servers that run project code start there only when pi itself trusts that project.
- **Complexity regressions get named:** an edit's result gains one short line for each named function the edit made more complex than the default branch has it, at or past the `high-complexity` thresholds.
