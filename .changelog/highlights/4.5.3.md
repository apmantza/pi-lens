### Highlights

- **Retained injections are on for Anthropic models, and their caps are yours:** findings pi-lens injects are now repeated unchanged by default on `anthropic-messages` models, so the provider's prompt cache keeps hitting (`contextInjection.retain: false` opts out). `contextInjection.retainMaxEntries`, `retainMaxBytes` and `retainMaxSessions` replace the fixed caps, and `0` removes a cap. (#5770)
- **Commit holds from a neighbour's cascade are clearer and fairer:** a held commit names what clears it, and a cascade note that reports no error no longer holds a commit refused. A blocker carried without a verdict says so once instead of on every write. (#5790, #5784)
- **Fewer false or stale results:** a clean markdown or Lua edit beside an auxiliary is confirmed clean, a single-range adapter edit clears a stale read record, a second session in one workspace keeps its own startup guidance, and a finding under a `..foo` directory keeps one id across checkouts. (#5774, #5762, #5792, #2556)
- **Processes and probes stay inside their bounds:** a hung runner left by a killed host is reaped, a timed-out fresh analyze ends with everything it started, language servers refuse project markers above the home directory, and global package-manager discovery is gated by root admission. (#5703, #4907, #5728, #5689)
- **Leaner and more configurable:** the Opengrep rule pack streams to disk, a tool you know never writes can skip the per-call tree comparison (`opaqueScan.nonWriterTools`), and log retention and size limits can be turned off. (#5701, #5793, #5771)
