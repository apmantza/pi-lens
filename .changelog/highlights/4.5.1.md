### Highlights

- **The commit gate judges what is actually staged:** under `--lens-guard` it refuses a blocker the staged lines add, whoever wrote them (a script, an external editor, a tool that names no path), and no longer refuses a commit over a blocker that was already in the file. It also sees commits that bash runs through escapes, Unicode spaces, `bash -c` or `eval` substitutions. (#5553, #5649, #5650, #5652)
- **Language-server calls end cleanly:** Esc returns an `lsp_navigation` call on a silent server at once, a cut-off check cancels its diagnostic pull and clean-confirm ping, and a dead or cancelled server no longer retires a code-action warning as clean. (#5097, #5258)
- **Runners find the tool your project uses and skip the one that cannot run:** a pyright that fails its version check is skipped, not run; a project's own `shellcheck` in `node_modules/.bin` is found; projects without a Python environment run tests with the pytest on PATH. (#5410)
- **Tools install again from their current releases:** Opengrep, Hadolint, Vale, shfmt and tflint follow their upstream asset names, and Helm installs on a machine that does not have it. (#5624, #5643)
- **An opt-in footer status shows diagnostics counts:** `--lens-issues-status` (or `ui.issuesStatus: true`) shows the widget's own error and warning tallies in the footer. Off by default. (#5588)
