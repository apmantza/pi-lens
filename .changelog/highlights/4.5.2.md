### Highlights

- **pi-lens cleans up after itself:** a language server now ends with the pi or MCP host that started it. That holds when the host quits, loses its client, takes a SIGTERM or crashes. On Linux and macOS pi-lens kills each held server's process group at host exit. On Windows a server behind a spaced path or an npm `.cmd` shim runs as pi's direct child. A host killed outright leaves a record, and the next start reaps its servers. Idle servers shut down, except five project indexers. Each server closes files past 256 open documents. The session-start sweep reaps old spill logs, session state, dead MCP sockets and orphaned project data. (#5694, #5699, #5744, #5700, #5702)
- **Untrusted and look-alike paths stay out of reach:** Python servers reach their global fallbacks for adopted projects. A PATH that reaches a project pi has not trusted skips its entries (#5674). On Windows an untrusted project's gopls or rust-analyzer no longer runs through an extensionless sibling such as a `.cmd` file (#5715). On Linux and macOS a directory named `proj\evil` no longer counts as inside `proj` (#5732).
- **STOP blocks say what they mean, and a fixed blocker stays fixed:** a cross-file blocker names the file it belongs to. A false-positive mark made from the block hides the finding instead of coming back on every edit. A file reached through a symlink no longer blocks its own export. A fixed ast-grep blocker no longer reads "Still unfixed" while the language server is silent. (#5710, #5709, #2556, #5727)
- **Diagnostics stay true to the bytes on disk:** an edit keeps the line ending of the edited line, and suppressing a finding no longer rewrites a CRLF file. An unconfirmed document names the server and cause. The cascade re-asks a push-only server about the dependents it answered before your edit. Deno projects use the Deno server for TypeScript files. A checkout or rebase in a sibling worktree refreshes the server. Esc cancels a project-wide diagnostics pull and the TypeScript project probe at once. (#5670, #5686, #5692, #5675, #5720, #5718, #5097)
- **Runners, installs and settings are leaner and clearer:** a prisma or Vite+ edit no longer starts a version-probe process per save. A project's own jscpd is found. Rubocop, rustfmt and rust-clippy no longer install without asking. Installer downloads have a size cap and a timeout. The diagnostics widget can move above the editor or hide when clean (`widget.position`, `widget.hideWhenClean`). The config readers agree on `ignorePaths`, `effective_config` tools and legacy files. (#5410, #5701, #5724, #5738)
