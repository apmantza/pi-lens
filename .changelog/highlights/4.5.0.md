### Highlights

- **A file pi-lens did not finish checking no longer reads clean:** `lens_diagnostics` says "unconfirmed" when a sweep stopped early, an analyzer failed, or a check is still pending, and a file whose checks were all skipped names each runner's reason (not installed, not configured, a timed-out version probe, a trust refusal). (#5258)
- **Lint findings for files that linters had silently skipped:** yamllint, markdownlint and oxlint now get the file path relative to the project, so an ignore glob that names a parent folder (such as `.claude/worktrees/`) no longer skips the file and reports it clean. `ast_grep_search` and `ast_grep_replace` no longer answer "no matches" in those checkouts. (#5544, #5556, #5545)
- **Rust, Go and TypeScript language servers report what they actually know:** a cold rust-analyzer no longer reads clean while it is still loading, a fixed `Cargo.toml`, `go.mod` or `go.work` reaches the running server without a restart, and TypeScript 7 installed as `@typescript/native` runs the native language server. (#5487, #5501, #5504)
- **Blockers stay visible without flooding the agent:** a blocker the agent cannot fix reaches it in full at most three times and then as a one-line pointer, and the footer keeps every file with findings, including two files with the same name. (#5532, #5460)
- **Tool configs above your home directory no longer count:** a `.prettierrc`, `.oxlintrc.json`, ESLint, Biome or similar config above `$HOME` no longer selects a tool for your project. (#5408)
