- **Opt-in widget-as-statuses placement** — `--lens-widget-status` (or `ui.widgetStatus=true` in `~/.pi-lens/config.json`) publishes each widget line as a `pi-lens-widget-NN` footer status instead of a below-editor component, so a footer that draws extension statuses can share its rows with them. Off by default; a host without statuses or a theme keeps the below-editor widget.
