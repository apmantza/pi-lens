- **Stale inline blockers from non-LSP analyzers (closes #2982)** — The turn-end freshness sweep skipped every record whose provenance was not all-`lsp`, so a tree-sitter or ast-grep blocker was never checked against its own file. Combined with a retire path that can only claim coverage for registered language servers, such a record could not be cleared by any number of clean diagnostics runs and re-served every turn for the rest of the session. The sweep now checks the record's own file for any entry that carries provenance, keeping the forward-import walk for LSP-sourced records only; records with no recorded sources stay fail-closed. That check is confirmed against content rather than mtime alone, so a `touch`, a checkout restoring identical bytes, or a no-op formatter pass no longer demotes a finding, and it re-arms, so bytes that come back un-demote the record. Self-drift demotions are deliberately outside the repeated-delivery cap that retires dependency-drift records, which keeps a security finding from being retired out of turn-end rendering. A demoted record still gates a commit, unchanged.
